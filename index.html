AeroStat

The status page you host yourself.

AeroStat checks your websites, APIs, servers and DNS, shows visitors how they are doing, and lets you post incidents and planned maintenance from a small admin panel. Open source, and running on your own server with Docker in a few minutes.

Live demo Docs GitHub
> docker compose --profile postgres up -d

Needs Docker and the two files from the install guide first. Postgres and Redis come with it.
